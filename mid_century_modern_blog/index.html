Reflection

Ironically the most difficult thing to reproduce from the reference image was altering the linked text, things like changing the color and removing the underline. I knew that I had to use the code ‘text-decoration: none;’ but for some reason it never worked. At first I put the code within a specific group, starting with just the menu, but it never changed. I tried putting the code at the start, I put it at the very end, and I tried putting multiple within the same group. It was only when I put it in the universal grouping did it work. I for sure would like more time to see if I can get this to work within a specific grouping, I read online that it’s most likely a priority thing but I’m not sure.

The only element of the blog that I couldn’t fully replicate was at the very end. The small social media and copyright text has a separate background color from the rest of the text. And giving this section its own background color kind of worked, some of the text did still had the light blue background from the universal grouping. I have no idea how to fix this, and if I had more time work on this then I’d like to understand what’s wrong with my code or if this is just because of the browser I’m using.
